# Семейный бюджет

Сайт для ведения семейного бюджета: доходы мужа и жены, ежедневные расходы по категориям, остаток для откладывания на большие нужды, диаграмма, сравнение с прошлым месяцем и выгрузка отчёта в Excel.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `family-budget`).
2. Нажмите **Add file → Upload files** и загрузите `index.html`, `README.md` и `.nojekyll`.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/family-budget/`.

## Важно

- Данные хранятся только в браузере (localStorage) на том устройстве, где вы открыли сайт. На другом устройстве или в другом браузере они не появятся.
- Для Excel-выгрузки нужен интернет: библиотека SheetJS подключается с cdnjs.
- Если очистить данные браузера, записи пропадут. Время от времени скачивайте отчёт в Excel как резервную копию.
